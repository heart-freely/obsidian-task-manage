# Tasks 插件设计参考

## 1. 任务完整格式

一个完整的任务行包含以下标记，按**固定顺序**排列：

```
执行状态 任务描述 优先级 循环周期 创建日期 计划日期 开始日期 截止日期 完成日期 取消日期 唯一ID 依赖ID 标签
```

### 1.1 标记字段说明

| 标记 | Emoji | 说明 | 示例 |
|------|-------|------|------|
| 执行状态 | 自定义 | 见下方状态映射 | `- [ ]` (未开始) |
| 任务描述 | - | 纯文本 | `制作初步音乐库` |
| 优先级 | 🔺⏫🔼🔽⏬ | 六个等级 | `🔺` (最高) |
| 循环周期 | 🔁 every ... | 重复规则 | `🔁 every week` |
| 创建日期 | ➕ | 任务创建日 | `➕ 2025-09-06` |
| 计划日期 | ⏳ | 计划执行日 | `⏳ 2025-09-06` |
| 开始日期 | 🛫 | 实际开始日 | `🛫 2025-09-06` |
| 截止日期 | 📅 | 截止日 | `📅 2026-04-06` |
| 完成日期 | ✅ | 实际完成日 | `✅ 2023-04-17` |
| 取消日期 | ❌ | 取消日 | `❌ 2023-04-18` |
| 唯一 ID | 🆔 | 任务标识 | `🆔 dcf64c` |
| 依赖 ID | ⛔ | 依赖的其他任务 ID 列表 | `⛔ dcf64c,h17ye` |
| 标签 | 🏁 | 自定义标签 | `🏁 keep` |

### 1.2 完整实例

```
- [x] 任务描述 🔼 🔁 every week ➕ 2025-09-06 ⏳ 2025-09-06 🛫 2025-09-06 📅 2026-04-06 ✅ 2023-04-17 🆔 dcf64c ⛔ dcf64c,h17ye 🏁 keep
- [ ] 任务描述 🔼 🔁 every week ➕ 2025-09-06 ⏳ 2025-09-06 🛫 2025-09-06 📅 2026-04-06 ❌ 2023-04-18 🆔 dcf64c ⛔ dcf64c,h17ye 🏁 keep
```

## 固定排序

> 以下顺序为本插件的自定义设计，用于整理箱等视图的“自动排序”功能，与 Tasks 插件内置行为无关。

当需要自动重排一个任务行的所有标记时，应遵循以下顺序：

1. 执行状态 🔲|❔|⏩|✅|❎|⬛
2. 任务描述 纯文本
3. 优先级 🔺|⏫|🔼|🔽|⏬
4. 循环周期 🔁
5. 创建日期 ➕
6. 计划日期 ⏳
7. 开始日期 🛫
8. 截止日期 📅
9. 完成日期 ✅
10. 取消日期 ❌
11. 唯一 ID 🆔
12. 依赖 ID ⛔
13. 标签 🏁

## 2. 自定义执行状态

插件使用自定义 emoji 表示状态，同时保留标准 Markdown 任务符号作为底层标识。  
以下映射关系为本插件的自定义设计。

| 状态名 | Markdown 符号 | 显示 Emoji | Tasks API 类型 |
|--------|---------------|------------|----------------|
| 积压中 | `- [ ]`       | 🔲         | `BACKLOG`      |
| 计划中 | `- [?]`       | ❔         | `TODO`         |
| 进行中 | `- [/]`       | ⏩         | `IN_PROGRESS`  |
| 已完成 | `- [x]`       | ✅         | `DONE`         |
| 已取消 | `- [-]`       | ❎         | `CANCELLED`    |
| 非任务 | `- [!]`       | ⬛         | `NON_TASK`     |

**固定排序（本插件自定义，用于分组/列表）**：  

1. 未开始 🔲
2. 计划中 ❔
3.  进行中 ⏩
4.  已完成 ✅
5.  已取消 ❎
6. 非任务  ⬛

## 3. 优先级映射

| 优先级名称 | Emoji | 数值 (Tasks API) | 排序权重（本插件自定义） |
|------------|-------|------------------|---------------------------|
| 最高       | 🔺    | 1                | 1                         |
| 高         | ⏫    | 2                | 2                         |
| 中         | 🔼    | 3                | 3                         |
| 低         | 🔽    | 4                | 4                         |
| 最低       | ⏬    | 5                | 5                         |
| 普通       | (无)  | 6      | 6                        |

**排序顺序（本插件自定义）**：由高到低 🔺 → ⏫ → 🔼 → 🔽 → ⏬→ 普通（无优先级）

## 4. 循环周期

循环任务通过 `🔁 every ...` 标记，支持以下周期：

- `🔁 every day` (每天)
- `🔁 every week` (每周)
- `🔁 every month` (每月)
- `🔁 every year` (每年)
- `🔁 every <n> days/weeks/months` (自定义间隔)
- 可带 `when done` 后缀，表示完成后立即创建下一次

周期排序（本插件自定义，短周期在前）

1. `🔁 every day` (每天)
2. `🔁 every week` (每周)
3. `🔁 every month` (每月)
4. `🔁 every year` (每年)
5. `🔁 every <n> days/weeks/months` (自定义间隔)

## 5. 日期标记与顺序

六个日期字段，按时间逻辑顺序排列（本插件自定义）：  

1. ➕ 创建日期 
2.  ⏳ 计划日期 
3.  🛫 开始日期 
4.  📅 截止日期 
5.  ❌ 取消日期 
6.  ✅ 完成日期

在自动排序或补全时，需保证：  
创建日期 ≤ 计划日期 ≤ 开始日期 ≤ 截止日期 ≤ 完成日期（取消日期可等于截止或完成日期）

## 6. 依赖标记

- `🆔` 定义任务的唯一标识符，用于被其他任务引用。
- `⛔` 列出当前任务所依赖的其他任务的 ID（可多个，逗号分隔）。  
  表示必须先完成这些依赖任务，才能开始本任务。

## 7. 标签

- `🏁 keep`：完成后保留此任务（不自动删除）。
- `🏁 delete`：完成后删除此任务或循环任务的当前实例。
- `🏁 xxx`：自定义其他标签值。
