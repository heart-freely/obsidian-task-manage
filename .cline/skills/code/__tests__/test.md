# 测试要点

## 单元测试覆盖要求

| 模块                            | 测试重点                                          |
| ------------------------------- | ------------------------------------------------- |
| `filter-task-process.js`        | 筛选组合（状态、日期范围、标记包含/排除）的正确性 |
| `read-tasks.js`                 | 自定义标记正则提取准确性                          |
| `common-process.js` (DateUtils) | 边界日期处理、周范围计算                          |

## 视图级关键测试场景

| 视图                 | 测试场景                                       |
| -------------------- | ---------------------------------------------- |
| 收集箱 (`inbox`)     | 仅显示 TODO 状态、非循环、优先级降序           |
| 逾期任务 (`overdue`) | `due < today`、未完成、非循环                  |
| 日历 (`calendar`)    | 任务在正确的日期格子中，线条连接首尾           |
| 甘特图 (`gantt`)     | 依赖箭头从完成时间指向开始时间，虚拟滚动不出界 |
| 整理箱 (`organize`)  | 编辑预览累积、快照撤回恢复原文、分页正确       |
| 统计分析 (`data`)    | 下钻统计数据准确，饼图与柱状图数据一致         |
| 任务树 (`tree`)      | YAML/Wiki 双源父任务解析结果正确，缺失提示     |
| 标签视图 (`tag`)     | AND/OR 模式过滤结果正确                        |

## 测试工具配置

- **单元测试框架**：Jest（配置文件 `jest.config.cjs`）
- **覆盖率目标**：核心处理模块 > 80%
- **E2E 测试**：暂无，建议使用 Obsidian 插件测试框架（如 `obsidian-plugin-tests`）

## 测试数据准备

- 使用 `__tests__/fixtures/` 中的示例任务文件
- 包含各类标记组合、边界日期、循环规则
