# 任务数据统计分析视图 Skill

## 文件
`src/panel/views/data-tasks-view.js`

## 功能
- 左侧任务树：展示任务层级结构，每个有子任务的节点显示进度条（各状态比例），支持折叠
- 下钻统计：点击树节点时，图表只统计该节点及其子任务的数据
- 右侧多维度图表：执行状态、优先级、循环周期、日期标记、依赖、标签等
- 图表类型切换：同维度可在饼图和堆叠柱状图之间切换
- 筛选联动：支持全局筛选条件（日期范围、隐藏完成/取消等）影响统计数据

## 实现方式
- 数据获取：`readTasks.getAllTasks` 配合当前筛选条件
- 统计计算：`calcul-chart-process` 提供各类聚合函数
- 图表渲染：ECharts 实例复用，通过 `setOption` 更新配置
- 下钻实现：维护 `currentTreeNode` 状态，点击树节点后重新调用统计函数，只计算节点子树内的任务

## 核心函数
- `getSubtreeTasks(node, allTasks)` → Task[]
- `calculateStats(tasks)` → statsObject
- `updateChart(chartInstance, stats, chartType)`

## 事件流

    树节点点击 → 更新 currentTreeNodeId → 计算子树统计 → 更新所有图表

    图表类型切换按钮 → 重新 setOption 同维度不同图表类型

    全局筛选变化 → 重新获取任务 → 刷新树和图表

## 数据流伪代码

    tasks = getAllTasks(dv, state)

    构建左侧树

    若存在下钻节点 → filtered = getSubtreeTasks(node, tasks)

    否则 filtered = tasks

    stats = calculateStats(filtered)

    遍历图表配置，调用 updateChart 更新

## 关键算法复杂度

    统计计算：O(n)

    子树收集：O(m)，m 为子树节点数

    图表更新：使用 ECharts diff，数据量 < 2000 流畅

## AI 命令
生成或修改统计分析视图时，请严格遵循：
- 数据处理：通过 `readTasks.getAllTasks` 获取数据，过滤条件来自全局状态或视图独立筛选。
- 图表库：必须使用 ECharts，并复用实例（通过 `echarts.init` 后保存引用，更新时调用 `setOption`）。
- 下钻逻辑：点击树节点时，收集该节点及其所有后代的任务集合，重新计算统计指标，更新图表，不重新获取原始数据。
- 进度条：在树节点右侧绘制，由未开始、计划中、进行中、已完成、已取消五段组成，颜色严格使用指定色值（#2e333b, #4b525b, #7fb8f0, #47852f, #c3393e）。
- 图表布局：饼图等使用网格布局，不可出现绝对定位导致的样式错乱；切换图表类型时保留当前维度筛选。
- 性能：当任务总数超过阈值时，仅渲染当前可视树节点，使用虚拟滚动或懒加载。

### 6.1.2 代码设计
本代码为 Obsidian 用户提供一个基于 DataviewJS 的任务看板，核心功能如下：

#### 任务看板功能要点（用户视角）
- 多维度时间筛选：支持年份、季度、月份、周、星期多级联动选择，可多选组合查询。
- 快捷范围按钮：一键切换今天、昨天、明天、本周、本月、所有任务。
- 自定义日期范围：手动输入起止日期，精确控制查询区间。
- 任务完成趋势图表：柱状图展示每日完成任务数，深色 Tooltip 显示 " 日期 数量 个 "。
- 任务列表分页：每页 100 条，支持上一页/下一页导航。
- 独立排序：可按时间、优先级（⏬🔽🔼⏫🔺）、完成状态单独排序，互不影响。
- 点击跳转原文：点击任务行直接打开源文件并定位到对应行。
- KPI 卡片：实时显示总任务数、已完成数、完成率。
- 加载更多历史数据：通过 " 加载更早任务 " 按钮扩展查询月份。
- 重置选中：一键清空所有级联筛选条件。

#### 任务看板代码设计要点（简洁版）
- 配置驱动：`CONFIG` 集中管理文件夹、分页、图表尺寸、默认月份，便于调整。
- 缓存优先：任务数据首次加载后缓存，后续查询直接过滤，避免重复遍历文件。
- 时间戳预计算：任务加载时计算 `_cachedTimeRange`，过滤时仅比较数值，无 `new Date()` 开销。
- CSS 类切换：按钮状态通过类名控制，`updateButtonStyles` 批量刷新，避免内联样式操作。
- 图表实例复用：全局 `chartInstance`，`setOption` 更新配置，无销毁重建。
- 模块化 UI：`buildFilterPanel`、`buildChartSection`、`buildTaskSection` 分离构建逻辑。
- 独立排序：时间、优先级、完成状态三组互斥，仅按当前选中维度排序，简化比较逻辑。
- 分页渲染：`DocumentFragment` 批量插入任务项，减少重排；仅渲染当前页，控制 DOM 数量。
- 错误隔离：图表渲染包裹 `try-catch`，失败时降级显示提示，任务列表不受影响。
- 主题适配：通过 `getComputedStyle` 读取 Obsidian CSS 变量，Tooltip 固定深色背景。
- 级联多选：年份→季度→月份→周→星期逐级启用，上级多选时下级禁用，范围取最早/最晚边界。
