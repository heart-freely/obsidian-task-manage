# 甘特图视图 Skill

## 文件
`src/panel/views/gantt-task-view.js`

## 功能
- 左侧任务树：基于文件层级构建可折叠的任务列表，支持排序
- 右侧时间轴：绘制任务条，长度对应时间范围，依赖关系用箭头表示
- 虚拟滚动：仅绘制可视区域内的任务行和任务条
- 交互：Alt+滚轮缩放、拖拽平移、悬停高亮、点击跳转源文件
- 筛选开关：循环/已完成/已取消、交集模式切换、隐藏文件夹

## 实现方式
- 纯 Canvas，分为三层：背景层（网格、日期）、主内容层（任务条、文字）、高亮层（悬停）
- 任务数据由 `readTasks.getAllTasks` 获取，并按树状关系组装（`tree-task-process`）
- 任务条绘制：使用 Path2D 预缓存圆角矩形路径，通过 `translate` + `scale` 复用
- 依赖箭头：从 🆔 任务的结束时间指向 ⛔ 任务的开始时间，折线带圆角，相同坐标去重
- 虚拟滚动：计算滚动偏移，只渲染 `startIndex` 到 `endIndex` 的任务行
- 状态持久化：筛选、折叠、缩放、滚动位置保存于 `ganttState`，刷新后恢复

## 核心函数
- `buildTree(tasks)` → treeNode
- `renderLoop()` → 绘制控制循环
- `drawBackground()` / `drawTasks()` / `drawDependencies()` / `drawHighlight()`
- `getVisibleRange()` → { startIndex, endIndex }

## 事件流

    加载数据 → 构建树 → 计算时间轴 → 初始绘制

    滚动/缩放 → 更新 scroll/zoom → requestAnimationFrame → 重绘可视区域

    悬停 → 计算悬停任务 ID → 绘制高亮层

    折叠/展开 → 更新 collapsedNodes → 重绘树和任务条

    筛选开关 → 过滤任务 → 重构建树 → 重绘

## 关键算法复杂度

    树构建：O(n)

    筛选：O(n)

    可视行计算：O(1) 根据偏移/行高

    任务条绘制：O(visibleCount)，约 <100 条

    箭头绘制：O(d) 依赖关系数

    使用 requestAnimationFrame 节流重绘

## AI 命令
生成或修改甘特图时，必须遵守：
- 数据源：统一使用 `readTasks.getAllTasks` 获取，通过 `tree-task-process` 构建树。
- 渲染：必须使用 Canvas 分层绘制，背景层独立不随滚动重绘；实现虚拟滚动（`startIndex`/`endIndex`），避免全量绘制。
- 依赖箭头：从 ID 任务完成时间侧中线末端到依赖任务开始时间侧左上角，路径用 `Path2D` 构建并缓存；当时间重合时需偏移避免遮盖。
- 交互缩放：绑定 Alt+鼠标滚轮实现缩放，禁止修改默认的 Obsidian 键盘快捷键；缩放范围限制在合理的比例内。
- 样式：任务条颜色从 CSS 变量中读取，保证亮/暗主题适配；状态颜色遵循全局约定（未开始 #2e333b 等）。

### 4.11.2 代码设计
该甘特图脚本的核心设计要点如下：

- 架构设计
  - 纯 Canvas 一体化绘制，左侧树与右侧时间轴共用画布，通过行索引精确对齐。
  - 分层画布：背景层（静态网格）、主内容层（任务条/文字）、高亮层（悬停效果），减少重绘范围。
  - 状态集中管理（`state` 对象），筛选结果缓存避免重复解析任务文件。
- 性能优化
  - 虚拟滚动：仅绘制可视区域内的行和任务条，大任务量下遍历次数从数千降至数十。
  - Path2D 预缓存圆角矩形路径，绘制时通过 `translate` + `scale` 复用，避免重复构建路径。
  - 依赖箭头去重：相同坐标的箭头只绘制一次，减少路径指令。
  - `requestAnimationFrame` 节流绘制，滚动/缩放时合并高频请求。
- 交互与体验
  - 悬停高亮独立层绘制，变化时仅重绘该层，消除闪烁。
  - Alt + 滚轮缩放，拖拽平移，边界限制防止视图溢出。
  - 工具提示直接挂载 `body` 并 `fixed` 定位，无视画布变换。
  - 状态持久化（筛选、折叠、缩放、滚动位置），刷新后恢复视角。
- 数据流
  - 任务解析：正则提取 Tasks 插件标记，`_cleanText` 强清理确保描述纯净。
  - 筛选链：日期范围 → 状态 → 包含/排除标记 → 循环/已完成/已取消开关。
  - 树构建：从根目录下一级开始，支持隐藏文件夹直接显示文件。
- 可维护性
  - 配置集中（颜色、圆角、线宽等），主题颜色通过 `getComputedStyle` 动态获取。
  - 函数职责单一，工具函数与绘制逻辑分离，便于调试和扩展。
