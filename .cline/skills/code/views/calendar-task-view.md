# 所有任务日历图视图 Skill

## 文件
`src/panel/views/calendar-task-view.js`

## 功能
- 根据查询到的任务最小/最大日期动态生成日、周、月、季、年视图
- 判断任务与日期交集：支持精确时间点（创建、开始、截止等）和区间（计划-截止、开始-完成）两种模式
- 周/月/季视图仅在任务起止日期显示完整描述，中间绘彩色过渡线条（颜色对应任务状态）
- 交互：点击任务跳转日视图聚焦、显示/隐藏循环/已完成/已取消任务、切换交集模式
- 年视图用颜色深浅表示完成任务数量

## 实现方式
- 渲染引擎：Canvas 或 ECharts
- 数据处理阶段预建“日期桶”：每个日期存储相关任务列表，并标记该任务是否为起止日
- 交集判断算法：
  - 单一日期：匹配创建、开始、计划、截止、完成、取消任一字段
  - 区间模式：计划日期 ≤ 日 ≤ 截止日期，或开始日期 ≤ 日 ≤ 完成日期
- 线条过渡：同一任务在非起止日绘制彩色条，颜色从预定义映射表中获取（基于执行状态）
- 样式以 `cal-` 前缀注入，避免污染全局

## 关键设计
- 动态视图生成：自动扩展周/月/季/年层级，无数据的层级只显示标题和提示
- 性能：DocumentFragment 批量构建 DOM，年视图事件委托

## 依赖
- ECharts / Canvas
- `DateUtils`
- `readTasks.getAllTasks`

## 修改指南
- 修改线条颜色：调整状态到颜色的映射表
- 添加新视图模式：在渲染分支中增加对应的生成逻辑（如半年视图）
- 改变交集判断：修改区间算法，可增加新的组合模式

## AI 命令
生成或修改日历视图时，请严格遵循：
- 数据获取：必须调用 `readTasks.getAllTasks`，在此基础上进行时间过滤。
- 视图生成规则：根据任务的时间范围自动推算出需要渲染的日/周/月/季/年视图，禁止硬编码固定时间范围。
- 交集判断：必须同时支持“任意日期字段等于当天”和“计划-截止/开始-完成区间包含当天”两种模式，并提供切换按钮。
- 线条颜色：根据任务状态（未开始、进行中、已完成等）映射到不同浅色系颜色，并适配 Obsidian 深色模式。
- 交互：点击周/月/季视图中的任务应跳转到日视图并聚焦该任务；隐藏循环/已完成/取消任务时直接过滤数据源，不重新请求 API。
- DOM 操作：禁止使用 `innerHTML`，所有元素通过 `createElement` 生成。

### 4.10.2 代码设计
- 状态集中：所有变量归入 `state` 对象，便于清理与调试。
- 配置分离：目录、尺寸、颜色、透明度统一在 `CONFIG` 中修改。
- 筛选缓存：指纹比对避免重复过滤；日期桶预建加速渲染。
- 全局排序：任务预先排序并挂载索引，格子内 O(1) 查序。
- 视图渲染：日/周/月/季/年独立函数，共用日期桶与排序。
- 交集判断：综合时间点与区间（计划 - 截止/开始 - 完成）判定任务归属。
- 首尾显示：仅在任务真实起止日显示完整描述，中间以彩色线条过渡。
- 性能优化：DocumentFragment 批量 DOM、年视图事件委托、CSS 切换展开。
- 内存管理：启动时清理旧样式与全局引用。
