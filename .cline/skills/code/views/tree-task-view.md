# 任务树视图 Skill

## 文件
`src/panel/views/tree-task-view.js`

## 功能
- 基于文件 YAML 父任务字段和 Wiki 链接构建多级任务树
- 支持折叠/展开、导出大纲
- 排除已完成/已放弃任务的开关

## 实现方式
- 双源解析父任务：YAML 父任务字段与 Wiki 链接
- 使用 `tree-task-process` 构建树
- 懒加载渲染，性能优化

## 核心函数
- `buildTree(tasks)` → TreeNode
- `renderTree(container, tree)`

## 数据流伪代码
1. tasks = getAllTasks(dv, state)
2. 解析父子关系（YAML + Wiki）
3. 构建树结构
4. 渐进渲染

## 修改指南
- 调整关系解析规则


## AI 命令
生成或修改任务树视图时，请遵循：
- 数据源：通过 `readTasks.getAllTasks` 获取带元数据的任务对象。
- 关系构建：必须实现双源解析（YAML + Wiki 链接），冲突时优先链接，缺失时在 UI 中给出提示。
- 渲染：采用渐进式渲染，折叠状态默认文件收起、任务展开；使用 `requestIdleCallback` 或等效的分批插入。
- 状态持久化：折叠状态保存至 `localStorage`，刷新后恢复。
- 导出功能：生成纯文本缩进列表，使用 `navigator.clipboard.writeText` 复制。

### 4.9.2 代码设计
- 🧱 架构分层
  - IIFE 封装：避免全局污染，通过 `window.initTaskTree` 暴露唯一入口。
  - 四大模块解耦：
    - `StateManager`：折叠状态内存缓存 + 防抖持久化。
    - `CacheManager`：文件哈希校验 + 增量失效监听。
    - `TreeBuilder`：纯数据转换，独立于 Obsidian API。
    - `Renderer`：DOM 生成、事件委托、渐进渲染。
- ⚡ 性能关键
  - 全局缓存：首次构建后数据挂载 `window`，切换笔记秒开。
  - 渐进式渲染：`requestIdleCallback` 分批插入根节点，避免长任务阻塞。
  - 懒加载子内容：仅展开时才渲染任务和子文件，大幅降低首屏 DOM 规模。
  - 惰性创建折叠箭头：叶子任务不生成 `toggle` 元素，减少 20%~30% 节点数。
  - CSS 优化：移除后代选择器，添加 `contain: layout style` 限制重绘范围。
- 🧠 智能关系推导
  - 双源父任务解析：同时读取 YAML `父任务` 字段与 Wiki 链接，自动处理冲突（优先链接）。
  - 缺失链接检测：基于实际 `children` 数组反向校验，避免字符串匹配误报。
- 🖥️ 交互与体验
  - 事件委托：单一监听器处理跳转/折叠，内存友好。
  - 折叠状态记忆：文件默认折叠（每次渲染重置），任务内部状态保留。
  - 导出大纲：一键生成 Markdown 缩进列表并复制到剪贴板。
- 🔧 可维护性
  - 配置集中：路径、字段、正则等常量统一管理。
  - 纯函数倾向：核心构建逻辑无副作用，便于测试。
  - 兼容 ES5：无箭头函数、模板字符串，适配 Obsidian 运行环境。
