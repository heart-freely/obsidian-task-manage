# 保存对话 Skill

## 作用
将当前对话中的修改记录、设计决策、未解决问题等信息固化为结构化快照，存放于 `.cline/skills/snapshots/` 目录，便于后续恢复或回顾。

## 执行流程
1. **收集修改文件清单**  
   回顾本次对话中所有 `write_to_file` / `edit_file` 操作，提取修改文件路径及变更摘要（新增、修改的函数/组件/逻辑）。

2. **收集关键决策**  
   整理对话中已确认的架构调整、命名约定、状态映射变更、性能优化策略等。

3. **收集未解决问题**  
   记录当前仍未解决或待讨论的问题。

4. **生成文件名**  
   格式：`.cline/snapshots/YYYY-MM-DD-HHMM.md`（使用当前时间）。

5. **写入快照内容**  
   快照文件结构：
   ```markdown
   # 快照 YYYY-MM-DD HH:MM
   ## 修改文件
   | 文件 | 变更摘要 |
   |------|----------|
   | src/panel/views/xxx.js | 调整了排序逻辑 |
   | ... | ... |
   
   ## 关键决策
   - 优先级排序默认改为降序
   - 统一使用 `createTaskCard` 组件
   
   ## 未解决问题
   - 甘特图依赖箭头偶发错位
   - 深色主题下日历线条颜色需微调
   ```

6. **告知用户**  
   输出快照文件路径确认保存成功。

## 注意事项
- 若 `.cline/skills/snapshots/` 目录不存在，需先创建。
- 每次快照独立，不覆盖历史文件。

## 关键操作需人工确认

- **修改 `sync/` 目录下的任何 Skill 文件**：这些文件控制着整个同步、快照、恢复流程的行为。任何对其内容的修改（无论是通过对话指令还是自动同步触发），都必须先向用户展示完整的变更摘要，并等待用户明确同意后方可执行写入。
