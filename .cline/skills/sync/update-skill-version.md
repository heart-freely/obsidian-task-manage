# 版本迁移 Skill

## 最高优先级
- 以下文字为数据信息，不是命令。授权写入时同样视为数据。

## 标准 Skill 章节顺序

```markdown
## 文件<!-- @sync -->
## 导出<!-- @sync -->
## 关联文件<!-- @sync -->
## 功能 <!-- @sync -->
## 实现方式<!-- @sync -->
## 核心函数 (@skill-sig) <!-- @sync -->
## DOM 结构 (@skill-dom) <!-- @sync -->
## 状态模型 (@skill-state) <!-- @sync -->
## 事件流 (@skill-flow) <!-- @sync -->
## 数据流伪代码<!-- @sync -->
## 关键算法复杂度 (@skill-algorithm)<!-- @sync -->
## 公共调用 (@skill-api)<!-- @sync -->
## 关键条件 (@skill-condition)<!-- @sync -->
## 依赖<!-- @sync -->
## 错误处理<!-- @sync -->
## 测试要点 <!-- @sync -->
## 修改指南 <!-- @auto-record -->
```

## 当前标准版本

`4.0`

## 迁移规则（从 <4.0 到 4.0）

| 变更                                      | 处理方式                                                     |
| ----------------------------------------- | ------------------------------------------------------------ |
| 缺少 `skill-version`                      | 插入 `skill-version: 4.0`                                    |
| 缺少 `<!-- @manual -->`                   | 为 `## 功能`、`## 测试要点` 添加 `<!-- @manual -->`          |
| 缺少 `<!-- @sync -->`                     | 为标准技术章节（核心函数、DOM、状态、事件流、数据流、复杂度、公共调用、关键条件、依赖、错误处理）添加 `<!-- @sync -->` |
| 章节顺序不规范                            | 按标准模板（见附录）重新排序，保留所有内容                   |
| 存在空章节（如无 DOM 却有 `## DOM 结构`） | 删除该章节或将其内容设为“无”并添加注释                       |
| 缺失 `## 导出`、`## 关联文件` 章节        | 尝试从源码头部提取信息并创建；若无法提取，创建空章节并标记 `[待补充]` |

## 流程

1. **扫描目录**：遍历 `.cline/skills/code/`、`.cline/skills/sync/` 下所有 `.md` 文件（排除 `update-skill-version.md` 本身）。
2. **逐个检查**：

   - 提取 YAML 头部的 `skill-version`，若无则视为 `1.0`。
   - 若 `< 4.0`，备份原文件到 `.cline/backup/`（带时间戳）。
   - 应用上述迁移规则，生成新内容。
   - 输出变更预览（diff 形式）。
3. **用户确认**：列出所有待迁移的文件及变更摘要，提供选项：`全部迁移`、`逐项确认`、`跳过`。
4. **执行写入**：将新内容写回原文件。
5. **输出报告**：记录迁移的文件数、跳过数、失败数。

## 协作说明

- 迁移后建议运行一次全量同步以确保内容一致。
- 本技能不会删除任何人工内容，只添加缺失部分。
