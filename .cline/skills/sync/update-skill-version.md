  # 版本迁移 Skill

  ## 当前标准版本
  `4.0`

  ## 迁移规则（<4.0 → 4.0）
  - 添加 `skill-version: 4.0`
  - 为 `## 功能`、`## 测试要点` 添加 `<!-- @manual -->`
  - 为标准技术章节（核心函数、DOM、状态等）添加 `<!-- @sync -->`
  - 将 `depends_on`（若存在 README 中）迁移到 Skill 内的 `## 依赖` 章节
  - 删除空章节或标记“无”
  - 按标准顺序重排章节

  ## 流程
  1. 扫描 `.cline/skills/code/` 和 `sync/` 下所有 `.md`。
  2. 逐个检查，若 `<4.0`，备份到 `.cline/backup/`，应用迁移规则。
  3. 输出预览，用户确认后写入。
  4. 建议迁移后运行全量同步。
