  # 检查一致性 Skill

  ## 一致性巡检
  1. 加载 `README.md` 映射表。
  2. 对每对文件：
     - 提取源码中所有 `@skill-*` 注释，生成内存中的“标准 Skill”。
     - 对比现有 Skill 文档的 `@sync` 章节。
     - 记录差异（仅源码新/仅 Skill 新/冲突）。
  3. 输出报告（表格），提供选项：
     - `修复所有非冲突项`（调用 `update-skill`/`update-code`）
     - `逐项修复`
     - `导出报告`

  ## 反向依赖分析
  - 当触发词为 `检查依赖` 时：
    1. 扫描所有 Skill 的 `## 依赖` 章节，构建依赖图。
    2. 若指定目标 Skill，列出所有依赖它的 Skill；否则输出完整依赖图（Mermaid）。
    3. 检测循环依赖并报警。

  ## 功能实现校验（触发词 `检查功能实现`）
  1. 用户指定 Skill 文件（或当前打开的 Skill）。
  2. 读取其 `## 功能`（人工描述）和对应源码。
  3. 调用 DeepSeek 分析源码是否实现每一条功能点。
  4. 输出报告：已实现、部分实现、未实现，并给出依据。

  ## 协作
  - 自动修复委托给正向/反向同步技能。
