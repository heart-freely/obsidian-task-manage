# 清理快照 Skill

## 作用
随着开发进行，`.cline/skills/snapshots/` 下会积累大量快照文件。本技能用于清理指定天数之前或数量超过阈值的旧快照，避免目录膨胀。

## 执行流程
1. **确认清理策略**  
   询问用户保留规则（若用户未指定）：
   - 保留最近 N 个快照（例如 10 个），删除更早的。
   - 保留最近 N 天的快照，删除更早的。
   - 或同时使用两者。

2. **扫描快照目录**  
   读取 `.cline/skills/snapshots/` 下的所有 `.md` 文件，解析文件名中的时间戳。

3. **筛选待删除文件**  
   根据策略筛选出需要删除的文件列表。

4. **确认删除**  
   向用户展示待删除文件清单及总数，请求确认：

   将删除以下 5 个快照文件：

    2026-04-20-0930.md

    2026-04-20-1500.md
    ...
    确认删除？ (y/n)
5. **执行删除**  
用户确认后，删除文件并告知结果。

## 注意事项
- 默认策略建议保留最近 20 个快照或最近 7 天的快照。
- 删除操作不可逆，请谨慎确认。
- 若目录为空或无需清理，直接告知用户。

## 关键操作需人工确认

- **修改 `sync/` 目录下的任何 Skill 文件**：这些文件控制着整个同步、快照、恢复流程的行为。任何对其内容的修改（无论是通过对话指令还是自动同步触发），都必须先向用户展示完整的变更摘要，并等待用户明确同意后方可执行写入。
