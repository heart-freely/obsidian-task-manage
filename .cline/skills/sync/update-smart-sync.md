# 统一同步 Skill

## 流程
1. 检测本次对话变更的文件（同 `update-skill` 变更检测）。
2. 分类：
   - 只有 `src/` 下 `.js` 变更 → 执行 `更新技能`
   - 只有 `.cline/skills/code/` 下 `.md` 变更 → 执行 `更新代码`
   - 两者都有 → 先执行 `更新代码`，再 `更新技能`
3. 参数：
   - `同步 --full` 或 `全量同步` → 执行 `全局同步技能` + `全局同步代码` + 结构对齐
   - `同步 --check` 或 `同步检查` → 执行 `检查一致性`
4. 输出执行摘要。
