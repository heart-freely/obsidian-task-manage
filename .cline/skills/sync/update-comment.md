# 更新注释 Skill（注释管理 & 规范文档）

## 注释规范（摘要）
- 文件头部必须含：`文件`、`描述`、`所属模块`、`依赖`、`对外导出`、`注意事项`、`@see`。
- `@skill-sig`、`@skill-dom`、`@skill-state`、`@skill-flow`、`@skill-condition`、`@skill-api`、`@skill-algorithm` 紧贴代码。
- 全局标签：`@skill-global-style`、`@skill-global-state` 用于架构汇总。

## 操作模式
- **增量更新**：仅补全本次修改文件的注释，更新缓存。
- **新增注释**：为缺失头部的文件生成标准头部和基础标签。
- **全局更新**：扫描所有文件，补全头部、修正 `@see`，重建缓存。
- **格式校验**：独立检查格式，自动修复可修复项。
- **删除注释**：删除指定标签或头部（需确认）。
- **锚点初始化**：为所有映射的源码添加 `// @skill-anchor: <标识>`。

## 协作
- 本 Skill 只负责源码注释，不读取 Skill 文档。
- 正向/反向同步依赖本 Skill 生成的注释和缓存。
