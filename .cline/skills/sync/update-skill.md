# 更新技能 Skill（全功能同步中枢）

统一管理 Skill 文件的创建、增量与全量同步，每次更新后自动校验格式。

**映射规则**  
`src/panel/views/xxx-view.js` → `.cline/skills/code/views/xxx-view.md`  
`src/panel/bars/xxx-bar.js`   → `.cline/skills/code/bars/xxx-bar.md`  
`src/tasks/**/*.js`           → 更新至 `.cline/skills/code/skill.md`

所有 Skill 文件均可通过源码注释、头部信息自动更新，涉及主观决策时提示确认。缺失 Skill 时自动创建，中间目录自动生成。

---

## 增量更新（默认）
**触发词**：`更新技能`、`同步技能`、`同步到文档`

**流程**  

1. 提取本次对话中修改过的 `src/` 文件。  
2. 按映射规则定位目标 Skill。若不存在则自动创建（见[自动创建](#自动创建)）。  
3. 读取源码头部、`@skill-*` 标签、函数签名等，全面更新 Skill 的对应章节（功能、核心函数、DOM、状态、事件流、数据流、复杂度、错误处理、样式、测试要点、依赖、公共 API 等）。  
4. 源码中无相关信息则保留原有描述。  
5. **自动校验**：对本次更新的 Skill 文件检查格式合规性（头部字段完整性、`@see` 有效性、章节结构等），发现可自动修复的问题立即修正，其他问题在摘要中提示。  
6. 输出更新与校验摘要。

---

## 全量同步
**触发词**：`全局更新技能`、`全局同步技能`、`校验技能`

**流程**  

1. 扫描 `src/panel/`、`src/tasks/` 下所有业务文件及现有 `.cline/skills/code/` 下的 Skill 文件。  
2. **结构对齐**  
   - Skill 缺失 → 自动创建。  
   - Skill 存在但源码已删除 → 提示用户移至 `trash/` 或 `archive/`，待确认后执行。  
   - 文件名不一致 → 提示重命名，确认后执行。  
3. **内容同步**：同增量更新，对所有 Skill 全面更新。  
4. **主架构 Skill 同步**：核心模块（`read-tasks.js`、`write-tasks.js` 等）的函数签名、数据模型变更同步到 `code/skill.md`。所有对 `code/skill.md` 的写入为关键操作，须遵循[确认规则](#关键操作需人工确认)。  
5. **自动校验**：全面检查所有 Skill 文件的格式合规性，自动修复可修复项，输出完整报告。  
6. 生成全量报告（新建、更新、校验结果、待确认项）。

---

## 自动创建
缺 Skill 时执行：  
1. 确定路径，递归创建目录。  
2. 生成标准 YAML 头部（中文 `name`、根据源码推断的 `description` 和触发词）。  
3. 填充章节骨架：文件、功能、实现方式、核心函数、DOM 结构、状态模型、事件流、数据流伪代码、复杂度、公共调用、关键条件、错误处理、依赖、修改指南、AI 命令等。  
4. 已可提取的信息自动填入（如从 `@skill-sig` 提取核心函数），其余标记 `待补充`。

---

## 关键操作需人工确认
以下操作执行前须展示变更摘要，获得用户明确同意后方可写入：  
- 修改 `code/skill.md` 的任何章节。  
- 修改 `sync/` 目录下的任何 Skill 文件（包括本文件）。  
- 删除、归档或重命名 Skill 文件。  
- 覆盖手动撰写的长段描述（存在冲突且无 `@skill-*` 佐证时）。

## 协作说明
- 源码注释更新后应运行本 Skill 同步设计。
- 注释规范详见 `sync/update-comment.md`，本 Skill 依据其定义的 `@skill-*` 标签提取信息。
