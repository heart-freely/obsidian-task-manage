# 恢复对话 Skill

## 作用
当需要继续之前中断的开发工作时，从 `.cline/skills/snapshots/` 中读取指定快照文件，重建对话上下文，帮助 AI 快速进入状态。

## 执行流程
1. **列出可用快照**  
   扫描 `.cline/skills/snapshots/` 目录，按文件名（时间）倒序列出最近 5 个快照。
   - 若用户指定了日期（如“恢复3天前的对话”），则筛选对应快照。

2. **选择快照**  
   默认选择最新的快照。若用户给出指令指定，则选择指定快照。

3. **读取快照内容**  
   获取快照中的：
   - 修改文件清单
   - 关键决策
   - 未解决问题

4. **摘要呈现**  
   向用户展示快照摘要，并确认：“是否基于此快照继续工作？”  
   示例：
   ```
   找到快照 2026-05-05-1430.md：
   - 修改了 inbox-task-view.js（添加了优先级排序）
   - 关键决策：统一使用 `createTaskCard`
   - 未解决问题：甘特图依赖箭头错位
   是否继续？
   ```

5. **注入上下文**  
   用户确认后，AI 将快照中的信息作为本次对话的已知背景，直接进入开发讨论。

## 注意事项
- 快照只是上下文参考，不会自动回滚代码或文件。
- 若快照中提到的文件已被后续修改，应提醒用户注意可能的冲突。

## 关键操作需人工确认

- **修改 `sync/` 目录下的任何 Skill 文件**：这些文件控制着整个同步、快照、恢复流程的行为。任何对其内容的修改（无论是通过对话指令还是自动同步触发），都必须先向用户展示完整的变更摘要，并等待用户明确同意后方可执行写入。
