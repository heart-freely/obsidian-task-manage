# Obsidian 任务管理插件设计

# 常量设计

## 任务标记格式

本插件使用自定义的任务行标记语法：

执行状态 任务描述 优先级 循环周期 创建日期 计划日期 开始日期 截止日期 完成日期 取消日期 唯一ID 依赖ID 标签

各标记的 Emoji、说明和示例如下表：

| 标记     | Emoji        | 说明                   | 示例              |
| -------- | ------------ | ---------------------- | ----------------- |
| 执行状态 | 自定义       | 见下方状态映射         | `- [ ]` (待办中)  |
| 任务描述 | -            | 纯文本                 | `制作初步音乐库`  |
| 优先级   | 🔺⏫🔼🔽⏬   | 六个等级               | `🔺` (最高)       |
| 循环周期 | 🔁 every ... | 重复规则               | `🔁 every week`   |
| 创建日期 | ➕           | 任务创建日             | `➕ 2025-09-06`   |
| 计划日期 | ⏳           | 计划执行日             | `⏳ 2025-09-06`   |
| 开始日期 | 🛫           | 实际开始日             | `🛫 2025-09-06`   |
| 截止日期 | 📅           | 截止日                 | `📅 2026-04-06`   |
| 完成日期 | ✅           | 实际完成日             | `✅ 2023-04-17`   |
| 取消日期 | ❌           | 取消日                 | `❌ 2023-04-18`   |
| 唯一 ID  | 🆔           | 任务唯一任务ID         | `🆔 dcf64c`       |
| 依赖 ID  | ⛔           | 依赖的其他任务 ID 列表 | `⛔ dcf64c,h17ye` |
| 标签     | 🏁           | 自定义标签             | `🏁 keep`         |

任务`id`一个或多个允许字符的数值一致:

- `abcdefghijklmnopqrstuvwxyz`
- `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
- `0123456789`
- 下划线(`_`)
- 短横线(`-`)

任务实例：

- 任务描述 🔼 🔁 every week ➕ 2025-09-06 ⏳ 2025-09-06 🛫 2025-09-06 📅 2026-04-06 ✅ 2023-04-17 🆔 dcf64c ⛔ dcf64c,h17ye 🏁 keep
- 任务描述 🔼 🔁 every week ➕ 2025-09-06 ⏳ 2025-09-06 🛫 2025-09-06 📅 2026-04-06 ❌ 2023-04-18 🆔 dcf64c ⛔ dcf64c,h17ye 🏁 keep

### 执行状态符号映射（v2.1.0）

任务列表项使用 Markdown 复选框符号表示执行状态：

| 状态键      | 符号        | 含义   | 图标 | 颜色    |
| ----------- | ----------- | ------ | ---- | ------- |
| todo        | ` `（空格） | 待办中 | 🔲   | #2e333b |
| scheduled   | `?`         | 计划中 | ❔   | #4b525b |
| in-progress | `>` `/` `\` | 进行中 | ⏩   | #7fb8f0 |
| completed   | `x` `X`     | 已完成 | ✅   | #47852f |
| cancelled   | `-`         | 已取消 | ❎   | #c3393e |

**注意**：空格 ` ` 是预设状态标记，任何匹配 TASK_REGEX 的任务行都是有效任务。

#### 实现补充（2026-06-11）

状态键名在代码中统一使用 `scheduled`（对应早期设计文档中的 `planned`）。任务元素定义中 `status.children` 的键名、符号映射表、名称映射表、颜色映射表和允许状态列表等所有相关常量均使用此键名。符号到状态键的映射通过遍历符号映射表构建，空格映射到 `todo`，问号映射到 `scheduled`，大于号、斜杠和反斜杠映射到 `in-progress`，小写和大写 x 映射到 `completed`，短横线映射到 `cancelled`。

### 任务标记顺序

当需要自动重排一个任务行的所有标记时，应遵循以下顺序：

1. 执行状态 ⬛|🔲|❔|⏩|❎|✅
2. 任务描述 纯文本
3. 优先级 无优先级|⏬|🔽|🔼|⏫|🔺
4. 循环周期 🔁
5. 创建日期 ➕
6. 计划日期 ⏳
7. 开始日期 🛫
8. 取消日期 ❌
9. 完成日期 ✅
10. 截止日期 📅
11. 唯一 ID 🆔
12. 依赖 ID ⛔
13. 标签 🏁

同类内部排序规则：

- 执行状态：非任务 → ⬛待办中 🔲 → 计划中 ❔ → 进行中 ⏩ → 已取消 ❎ → 已完成 ✅
- 优先级：无优先级 → ⏬ → 🔽 → 🔼 → ⏫ → 🔺
- 循环周期：`🔁 every day` → `🔁 every week` → `🔁 every month` → `🔁 every year` → `🔁 every <n> days/weeks/months`
- 日期标记：➕ 创建日期 → ⏳ 计划日期 → 🛫 开始日期 → ❌ 取消日期 → ✅ 完成日期 → 📅 截止日期

#### 实现补充（2026-06-11）

排序操作对象实现了标记重排方法，按固定顺序（优先级、循环、创建、计划、开始、截止、完成、取消、标签、唯一标识、引用标识）重新排列任务行中的所有标记。自动补全方法在补全时间标记前后各调用一次排序方法确保最终顺序正确。

### 布局与交互

- **展开/折叠**：
    - 侧边栏整体可向右侧收缩或展开。折叠时仅显示视图按钮的 Emoji 图标（如未设置则显示名称首字符），展开时显示 `emoji + 文字` 的完整按钮。
    - 折叠和展开按钮使用 ◀ / ▶ 图标。
    - 侧边栏类在展开时通过按钮内容自适应计算宽度：先重置所有按钮宽度为自适应，获取实际内容宽度，取最大宽度作为统一按钮宽度，将所有按钮设置为该宽度，容器右内边距清零，最终宽度等于最大按钮宽度加左内边距。新旧宽度差超过一个像素时才更新。折叠时固定宽度为 40 像素。

- **宽度调整**：展开模式下，侧边栏宽度可拖动调整，最小宽度 48px，默认 200px。折叠时固定 40px。
- **顶部按钮行**：展开时仅显示折叠按钮（◀）；折叠时仅显示展开按钮（▶）。
- **视图列表**：按预设分组显示视图按钮，每个按钮旁无独立设置齿轮；全局设置按钮统一控制当前激活视图的工具栏。

#### 实现补充（2026-06-11）

面板管理器采用单例模式，统一管理八个功能面板的生命周期。八个面板的默认排列顺序为：筛选状态、筛选描述、筛选标记、筛选时间、任务视图、视图隐藏、视图排序、视图配置。面板实例通过映射表缓存，切换预设时复用已存在的面板，不重新创建。检测到输入框聚焦时跳过面板内容重建，保护用户输入不被中断。面板高度通过拖拽手柄调整，范围限制为 30 像素至视口高度的 85%。面板折叠时容器隐藏仅保留手柄，内容区上边距调整为手柄高度。

### 筛选描述栏

支持多段关键字搜索，以空格分隔，多段关键字逻辑关系为且。

#### 实现补充（2026-06-11）

筛选描述栏类实现双层输入保护机制。第一层维护当前输入值缓存，全局状态管理器触发重渲染时若检测到已有输入框，仅同步值而不重建 DOM 元素。第二层由面板管理器检测输入框聚焦状态，若聚焦则跳过整个面板内容重建过程。

#### 实现补充（2026-06-11）

时间计算模式支持四种取值：任意时间模式（默认，任一日期匹配即视为在范围内）、计划到截止模式（使用计划日期和截止日期，无截止日期回退到完成日期）、开始到完成模式（使用开始日期和完成日期，无完成日期回退到取消日期，再无则回退到截止日期）、无模式（不做时间筛选）。业务视图基类的回退默认值为计划到截止模式，各默认预设将其覆盖为任意时间模式。日历图和甘特图在时间模式为无时回退为任意时间模式以保证视图正常显示。

时间筛选栏类包含三个子按钮切换时间计算模式："任意时间"对应任意时间模式、"计划时间"对应计划到截止模式、"执行时间"对应开始到完成模式。

#### 任务查询时间模式切换

任务时间计算方式选择按钮，计划~截止， 开始~完成两个状态切换

- 固定条件
    - 创建时间，开始时间，完成时间，计划时间，截止时间，取消时间有一个时间与日历中某天日期相同，判断为任务时间和日历时间有交集
- 切换条件
    - 添加一个按钮，默认，计划时间~截止时间
    - 默认选中，使用计划时间~截止时间判断任务和日历时间有交集
    - 选中，使用开始时间~完成时间判断任务和日历时间有交集
        - 开始时间~完成时间（缺少完成时间则使用截止时间）

#### 实现补充（2026-06-11）

动态滑动条使用增强型双滑块组件。偏移为零的位置（今天）用强调色重点标记。说明文字显示"本日"等（偏移零）或"前/后若干日/周/月/季/年"（非零），文字宽度固定为 160 像素不换行。日、周、月、季级别不允许跨年，年级别允许跨年范围固定为前后五年。默认两个手柄在"本日"位置重合。切换动态单位时仅重建动态滑动条的 DOM 结构。

静态滑动条年级别范围固定为当前年份加减十年。同一年份时季、月、周、日级别为全范围，跨年时累加所有涉及年份的单位总数。格式化使用循环逐年减去单位数来确定所属年份。拖动任一级别的静态滑动条后所有级别同步刷新。今天刻度使用两像素宽八像素高的强调色标记。单值格式如"2026年"、"2026/2季"、"2026/6月"、"2026/23周"、"2026/6/1日"。

年份数据缓存机制确保每个年份的天数、周数、首个星期一的日期和最后一个星期日的日期仅计算一次。年初一月一日的周数强制为第一周，年末十二月三十一日的周数强制为最后一周。

##### 隐藏机制性能对比

本版本将隐藏机制从"树节点删除重建"改为"设置 display 标志"，性能对比如下：

| 维度     | 旧版（树重建）                 | 新版（display标志）            |
| -------- | ------------------------------ | ------------------------------ |
| 隐藏操作 | 递归创建新树，每次产生新对象   | 递归设置布尔值                 |
| 恢复操作 | 需从原始数据重新筛选构建新树   | 重新遍历设置可见               |
| 渲染跳过 | 树结构中已无该节点             | 渲染函数首行判断               |
| 内存分配 | 每次隐藏/恢复产生新树对象      | 单棵树加一个布尔字段           |
| 频繁切换 | 每次切换隐藏选项触发完整树重建 | 仅遍历设置标志位，不创建新对象 |

实现方式：遍历树设置每个节点的显示标志。父任务被隐藏时，子树一并隐藏。

##### 空列自动隐藏

表格渲染时自动检测每列的值：如果某一列在所有数据行中的值均为空字符串，则该列整体不渲染（表头和数据行均跳过）。

判断逻辑：遍历所有数据行，检查每列的取值函数返回值。如果所有行该列值为空字符串，标记为隐藏。用户通过隐藏面板控制的列也参与空列判断。

示例：如果当前筛选条件下所有任务都没有标签，则标签列自动隐藏；当筛选条件变化后出现有标签的任务时，该列自动恢复显示。

#### 实现补充（2026-06-11）

任务树构建函数处理文件间父子关系的五种情况：元属性和链接都缺失则忽略无父子关系；链接缺失元属性不缺失则取元属性；元属性缺失链接不缺失则取链接；元属性和链接都不缺失且不相同则取链接；元属性和链接都不缺失且相同则取元属性。优先使用元属性声明，其次使用链接引用。检测循环引用通过向上遍历父节点并使用已访问集合防止死循环。

文件关系结构记录声明父节点名称、解析到的声明父节点、声明本节点为父的子节点列表、链接的子文件名列表、解析到的链接子节点列表、链接本节点的父节点列表、冲突类型（元属性不匹配、缺失元属性、缺失链接）、未能解析的链接列表。

内容节点到任务树节点的转换函数保留标题级别（仅标题类型）和标题文本。自动识别函数遍历内容节点树，将有子列表任务（匹配任务正则）的标题提升为标题任务并设置默认任务数据。

任务树渲染函数支持聚焦子树模式。聚焦模式下显示"返回"标题栏，点击恢复全树。全树模式下显示虚拟根节点"任务管理"加合并进度条和总数。每行使用统一的行容器结构：折叠按钮（十六像素宽，显示向下或向右箭头）或占位符、内容容器（包含紧凑卡片、进度条、百分比、数量徽章）、右侧弹性空间。折叠按钮点击切换子节点显示和隐藏，触发树切换自定义事件。进度条统计函数收集所有子孙任务的各状态数量，通过路径和行号组合去重。

缩进宽度为二十四像素。同一节点下子任务按固定分组顺序排列（列表任务、标题任务、文件任务），若指定排序方式则各组内部按指定字段排序。行渲染回调在行容器添加到父元素之后调用，供甘特图附加甘特条使用。

##### 折叠更新机制

1. 获取左侧树容器的实际渲染宽度

6. 遍历所有甘特条，更新位置
7. 重绘依赖箭头 SVG

#### 实现补充（2026-06-11）

甘特图基于 DOM 渲染而非 Canvas。渲染函数返回一个对象，包含任务映射表（存储任务标识到节点的映射，供依赖箭头使用）、重绘方法和销毁方法。

时间轴头部构建函数根据每日宽度确定显示层级：每日宽度大于等于四十像素时显示年月季周日全部五层，大于等于十五像素时显示年月季周，大于等于五像素时显示年月季，大于等于一点五像素时显示年月。各层高度平均分配头部总高度（四十八像素）。从底层到顶层渲染：日层、周层、月层、季层、年层。今日线使用两像素实线强调色。

甘特条高度二十像素，圆角四像素，颜色使用状态颜色映射。已完成任务显示进度填充（半透明绿色）。右侧显示时长标签（天数显示为若干天、周数显示为若干周、月数显示为若干月、年数显示为若干年）。提示框第一行显示节点任务文本（带类型标记）加换行加完整任务信息。

依赖箭头使用可缩放矢量图形（SVG）绘制。路径计算为折线：从源任务完成时间侧中线末端到目标任务开始时间侧左上角，带箭头三角形。悬停时使用十四像素透明描边扩大可点击区域。SVG 元素暴露重绘方法供折叠更新调用。

缩放功能通过按住 Alt 键加滚轮实现。每日宽度范围为零点五到四十像素，缩放步进为乘以一点三或零点七。缩放以鼠标位置为中心保持时间点不变。缩放状态持久化到本地存储。默认每日宽度为四十像素。

折叠更新机制监听树切换自定义事件。在请求动画帧回调中执行：获取左侧树容器的实际渲染宽度、更新内容区总宽度、更新时间轴头部（间隔宽度、内部左偏移、头部总宽度）、移除并重建网格背景、移除并重建今日线、遍历所有甘特条更新位置、调用 SVG 重绘方法更新依赖箭头。

##### 自动补全标记

- 编辑目标：补全截止时间标记，开始时间标记，计划时间标记
    - 自动补全任务时间标记，允许配置执行时间
        - 判断是否存在任务完成时间，存在才补全和修改，不存在就跳过。
        - 开始补全前先对标记排序，保证标记顺序正确。
            - 补全时设置参数
                - 可指定任务执行时间为 n 天，即开始日期为截止日期的第前 n 天，继而计算出开始日期。
                - n 大于等于 0
        - 补全和修改的可能情况
            - 不缺失时间标记
                - 判断开始时间和完成时间相隔是否 n 天
                    - 不是相隔 n 天
                        - 按照整体补全和修改逻辑的方法修改
                    - 是相隔 n 天
                        - 保持原有的标记时间不变
            - 缺失单个时间标记
                - 按照整体补全和修改逻辑的方法补全
            - 缺失多个时间标记
                - 依次使用缺失单个时间标记的方法补全，直到全部补全
        - 整体补全和修改逻辑
            - 从完成日期开始往前补全和修改，因为截止日期是最晚的日期，最早日期是创建日期。
                - 创建日期小于等计划日期，计划日期小于等于开始日期，开始日期小于等于完成日期，截止日期等于完成日期，
                - 依次寻找截止时间标记，完成时间标记，开始时间标记，计划时间标记，
                - 使用前一个标记的时间补全后一个标记
                - 判断后一个标记的后一个标记的时间是否大于后一个标记的时间。
                    - 如果大于
                        - 就将后一个标记的后一个标记的时间改为小于等于后一个标记的时间。
                            - 如果后一个标记是开始时间
                                - 根据 n 的值补全和修改开始时间
                    - 如果小于等于
                        - 后一个标记的后一个标记的时间不变

#### 实现补充（2026-06-11）

整理处视图覆写渲染方法实现批量编辑界面。四种筛选模式对应四个按钮（未完成且缺失、未完成且完整、已完成且缺失、已完成且完整），通过筛选模式状态控制显示哪个按钮组。必需标记的判断条件为优先级不为无且创建时间、计划时间、开始时间、截止时间均存在。

编辑操作对象提供各标记的设置和删除方法。替换标记函数接受行文本、正则表达式和新标记内容（新标记为空时删除标记）。补全时间方法流程为：匹配完成日期（无完成日期返回原行）、先排序、设置截止日期等于完成日期、计算开始日期等于完成日期减去指定天数（默认三天）、计划日期等于开始日期、创建日期等于开始日期、再次排序。排序标记方法按固定顺序（优先级、循环、创建、计划、开始、截止、完成、取消、标签、唯一标识、引用标识）重新排列。

编辑工具栏包含：全选和全不选切换按钮、各标记编辑按钮组（优先级、循环、创建、计划、开始、截止、完成、取消、标签、唯一标识、引用标识）、补全时间按钮（默认三天）、排序标记按钮。任务列表每行包含复选框、原始文本、预览文本（编辑后显示"预览:"前缀）、确定按钮（已确认显示"已保存:"前缀和撤回按钮）。底部操作栏包含保存所有修改按钮和撤回上次保存按钮。

批量写入函数按文件路径分组修改项，对每个文件调用文件处理方法逐行替换。快照管理通过本地存储实现，加载和保存快照数组（最多五个），每次保存前自动创建新快照（记录被修改任务的原始文本到时间戳映射）。撤回时读取最近快照恢复原始文本。

单个编辑器和批量编辑器当前为占位文件，功能通过整理处视图直接实现。

#### 新架构中的持久化与配置

- 所有视图方案（`presets`）和全局状态（`sidebarCollapsed`、`sidebarWidth` 等）通过 `Store` 的 `saveFn` 自动序列化到 Obsidian 插件数据中，重启后恢复。
- 插件设置面板（`settings.ts`）提供任务文件夹路径、根路径、每日工时等全局配置。
- 单个视图方案的配置导入/导出通过"视图配置"栏实现，可保存为 JSON 文件，便于备份和分享。
- 移除了显示工具栏和曾展开过工具栏字段，视图配置面板始终可见
- 移除了 Store 中的智能继承逻辑

#### 实现补充（2026-06-11）

全局状态管理器在状态更新时自动调用保存函数将完整状态序列化到 Obsidian 插件数据中。保存函数合并插件设置数据（任务路径和四级过滤器配置）与全局状态数据后统一持久化。插件加载时从保存数据中恢复预设列表，与默认预设合并（非空数组优先使用保存值，空数组回退默认值）。视图是否上次打开状态独立于全局状态存储，用于判断插件重载后是否恢复视图。

整理处编辑快照通过本地存储以 JSON 格式保存（键名为整理快照键），最多保存五个。甘特图缩放状态通过本地存储保存（键名为甘特图缩放状态键），存储每日宽度值。

设置面板支持多行任务路径配置（逗号分隔），提供文件夹下拉搜索功能（调用全部已加载文件方法获取文件夹列表）。四级过滤器每级支持添加多条规则，每条规则包含模式文本、大小写敏感切换、全词匹配切换、正则匹配切换、排除模式切换。所有设置通过更新任务文件配置函数实时生效，无需重启插件。

#### 文件识别过滤器

插件支持四级过滤器体系，用于精确控制哪些文件被识别为任务文件：

| 级别         | 说明           | 匹配目标             | 示例                      |
| ------------ | -------------- | -------------------- | ------------------------- |
| 文件夹过滤器 | 匹配文件夹路径 | 文件所在目录         | 包含任务的文件夹          |
| 文件过滤器   | 匹配文件名     | 文件名（不含扩展名） | 以任务.md结尾             |
| 标题过滤器   | 匹配文件内标题 | Markdown 标题文本    | 包含任务的标题            |
| 任务项过滤器 | 匹配任务符号   | 任务复选框符号       | x（已完成）、空格（待办） |

每个过滤器支持：普通字符串包含匹配、正则表达式匹配、大小写敏感/不敏感、全词匹配、包含/排除模式。支持多根路径设置，设置面板提供文件夹搜索下拉。

## 工作区

工作区是多个视图方案和侧边栏布局的综合体，将在后续版本中实现。

通过切换工作区，用户可以快速改变侧边栏的按钮布局、分组、显隐状态，同时加载该工作区关联的所有视图方案。这允许用户为不同项目或场景保存完全不同的配置组合。

多个视图配置组合在一起，形成用户的**工作区**概念（未来版本实现一键切换工作区）。
