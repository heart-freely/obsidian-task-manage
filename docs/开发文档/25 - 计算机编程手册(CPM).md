# 计算机编程手册(CPM)

## 说明

1. 《计算机编程手册》(CPM)提供了一个程序员理解如何在给定的计算机上编程所需的信息。本手册专注于计算机本身，而不是运行于计算机上的特定软件。
2. CPM主要针对新开发的计算机、特定用途的计算机、其他不能利用商用的或其他编程手册的计算机。
