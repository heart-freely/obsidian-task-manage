# 软件需求规格说明(SRS)

## 说明

1. 《软件需求规格说明》(SRS)描述对计算机软件配置项CSCI的需求，及确保每个要求得以满足的所使用的方法。涉及该CSCI外部接口的需求可在本SRS中给出：或在本SRS引用的一个或多个《接口需求规格说明》(IRS)中给出。
2. 这个SRS，可能还要用IRS加以补充，是CSCI设计与合格性测试的基础。
